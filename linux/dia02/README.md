# Dia 2 - Sistema de arquivos Linux

## Conceitos revisados

- `/` representa a raiz do sistema
- `~` representa a pasta home do usuário
- `.` representa o diretório atual
- `..` representa o diretório pai
- `/home/techadmin` é o diretório pessoal do usuário techadmin

## Comandos praticados

- pwd
- ls
- ls -l
- ls -a
- ls -la
- cd
- mkdir
- touch
- cp
- mv
- rm

## Laboratório

Foi criada uma estrutura fictícia de empresa com diretórios de:

- financeiro
- suporte
- TI
- configuração oculta

Também foram praticados caminhos absolutos e relativos.
